# 🏆 Awesome Sports Performance Analytics

## 🌟 Top Sports Performance Analytics Platforms Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects** 🚀  
*Focused on Athlete Tracking, Video Analysis, Load Management, Tactical Insights & Sports Science* 📊  
**Last updated: August 2026** 📅

This repository tracks notable **SaaS platforms** and **open-source projects** for **Sports Performance Analytics**. These tools capture wearable and optical tracking data, analyze video, measure athlete load and readiness, generate tactical and event insights, support injury risk management, and deliver performance intelligence to coaches, analysts, and sports science staff across professional and elite sport.

**Examples** include Catapult Sports, Hudl, Kitman Labs, Kinduct, StatsBomb, Second Spectrum, KINEXON, SkillCorner, Edge10, and Sportlogiq (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project for computer-vision tracking, biomechanics, video analytics, open event data, pose estimation, and self-hosted performance tooling — ideal for sports scientists, analysts, developers, and teams building transparent, customizable performance systems.

Contributions welcome! 🎉 Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## 💻 Open-Source GitHub Projects

- **[StatsBomb Open Data](https://github.com/statsbomb/open-data)** [![Stars](https://img.shields.io/github/stars/statsbomb/open-data?style=social&color=white)](https://github.com/statsbomb/open-data/stargazers)  
  Free football event data released by StatsBomb, widely used by the analytics community for research, modeling, and visualization.

- **[mplsoccer / socceraction](https://github.com/andrewRowlinson/mplsoccer)** [![Stars](https://img.shields.io/github/stars/andrewRowlinson/mplsoccer?style=social&color=white)](https://github.com/andrewRowlinson/mplsoccer/stargazers)  
  Popular open-source libraries for football data visualization, pitch plotting, and advanced event-data modeling.

- **[analytics-handbook](https://github.com/devinpleuler/analytics-handbook)** [![Stars](https://img.shields.io/github/stars/devinpleuler/analytics-handbook?style=social&color=white)](https://github.com/devinpleuler/analytics-handbook/stargazers)  
  Jupyter Notebooks associated with the Toronto FC Analytics Handbook.

- **[Sports2D](https://github.com/davidpagnon/Sports2D)** [![Stars](https://img.shields.io/github/stars/davidpagnon/Sports2D?style=social&color=white)](https://github.com/davidpagnon/Sports2D/stargazers)  
  Open-source tool that computes 2D human pose and joint/segment angles from video or webcam, with optional OpenSim kinematic optimization.

- **[Roboflow Sports](https://github.com/roboflow/sports)** [![Stars](https://img.shields.io/github/stars/roboflow/sports?style=social&color=white)](https://github.com/roboflow/sports/stargazers)  
  Open computer-vision toolkit and datasets for sports (player detection, ball tracking, pitch keypoints) built on modern models.

- **[OpenBiomechanics](https://github.com/drivelineresearch/openbiomechanics)** [![Stars](https://img.shields.io/github/stars/drivelineresearch/openbiomechanics?style=social&color=white)](https://github.com/drivelineresearch/openbiomechanics/stargazers)  
  Driveline Baseball initiative providing anonymized elite athletic motion-capture (C3D) and processed biomechanics data.

- **[SportsLabKit](https://github.com/AtomScott/SportsLabKit)** [![Stars](https://img.shields.io/github/stars/AtomScott/SportsLabKit?style=social&color=white)](https://github.com/AtomScott/SportsLabKit/stargazers)  
  Python package for turning sports video into structured tracking data with multiple object trackers and pitch calibration.

- **[soccerEye](https://github.com/tigboatnc/soccerEye)** [![Stars](https://img.shields.io/github/stars/tigboatnc/soccerEye?style=social&color=white)](https://github.com/tigboatnc/soccerEye/stargazers)  
  Modular open-source toolkit for soccer footage analytics including field isolation, player detection, tracking.

- **[soccer-video-analytics](https://github.com/wku-crl/soccer-video-analytics)** [![Stars](https://img.shields.io/github/stars/wku-crl/soccer-video-analytics?style=social&color=white)](https://github.com/wku-crl/soccer-video-analytics/stargazers)  
  Code for extracting events and tracking data from broadcast soccer videos.

- **[unified-soccer-analytics](https://github.com/FatControlla/unified-soccer-analytics)** [![Stars](https://img.shields.io/github/stars/FatControlla/unified-soccer-analytics?style=social&color=white)](https://github.com/FatControlla/unified-soccer-analytics/stargazers)  
  Open-source video analytics platform synthesizing tracking, predictive models (xG, outcomes), and reproducible pipelines.

- **[AthletiQ](https://github.com/milansinghal2004/AthletiQ)** [![Stars](https://img.shields.io/github/stars/milansinghal2004/AthletiQ?style=social&color=white)](https://github.com/milansinghal2004/AthletiQ/stargazers)  
  AI biomechanical analysis pipeline oriented toward cricket technique and performance diagnostics.

- **[OpenPlaybook](https://github.com/sagars2004/OpenPlaybook)** [![Stars](https://img.shields.io/github/stars/sagars2004/OpenPlaybook?style=social&color=white)](https://github.com/sagars2004/OpenPlaybook/stargazers)  
  Semantic search and exploration platform for play-by-play sports data using natural-language queries.

- **[SportsReview](https://github.com/andrewjrobinson/SportsReview)** [![Stars](https://img.shields.io/github/stars/andrewjrobinson/SportsReview?style=social&color=white)](https://github.com/andrewjrobinson/SportsReview/stargazers)  
  Open-source video delay and frame-by-frame analysis tool useful for technique review.

- **[Awesome Sports AI](https://github.com/moose-lab/awesome-sports-ai)** [![Stars](https://img.shields.io/github/stars/moose-lab/awesome-sports-ai?style=social&color=white)](https://github.com/moose-lab/awesome-sports-ai/stargazers)  
  Curated collection of open-source sports AI tools, datasets, models, and runnable prototypes.

### 🛠️ Additional Strong Open-Source Options

- **Pose estimation stacks**: MediaPipe, RTMPose, OpenPose, and related tools for markerless biomechanics.
- **Tracking algorithms**: ByteTrack, DeepSORT, BoT-SORT implementations adapted for sports.
- **Event & tracking data projects**: openfootball, Metrica Sports sample data, StatsBomb/Wyscout community tools.
- **Biomechanics & force-plate analysis** notebooks and OpenSim pipelines.
- **Self-hosted fitness/athlete dashboards** (Endurain-style) and wearable data importers.
- Many community **xG models**, **pitch control**, **space creation**, and **load monitoring** repositories.

**Frameworks for building custom systems**: Combine **Roboflow Sports / SportsLabKit** for video tracking, **Sports2D or MediaPipe** for pose and angles, **StatsBomb Open Data + mplsoccer** for event analytics, and open biomechanics datasets to create a complete self-hosted sports performance analytics stack. 🏗️
